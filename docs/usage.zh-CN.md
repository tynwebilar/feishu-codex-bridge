# 使用说明

[English](usage.md) · [安装指南](../INSTALL.zh-CN.md) · [首页](../README.zh-CN.md)

适用于 Windows x64。本机运行，电脑关机、休眠、注销或断网都会影响服务。插件是管理入口，消息由独立后台处理。

## 初始化

安装插件后告诉 Codex“帮我初始化飞书 Codex 桥接”，或使用完整 Windows 包的菜单。凭据只在本机交互窗口输入，不发到聊天，不提交 Git。初始化不会自动扩大权限。

### 使用完整 Windows ZIP

1. 解压完整目录，双击 `Start.cmd`。保留 runtime、src、node_modules 的相对位置。
2. 选择「Codex 登录」，使用你自己的账号；已有本机 Codex 配置时复用本机配置。使用自定义模型服务的用户按自己的 Codex 配置操作。
3. 在飞书开放平台创建自己的企业自建应用，开启机器人并发布版本。配置事件订阅使用长连接，订阅 `im.message.receive_v1`。申请接收私聊消息、以应用身份发送消息及获取消息资源的相应权限；群聊还需接收群内 @ 机器人的消息权限。发送文件还需应用身份权限 `im:resource:upload`（或包含该能力的 `im:resource`），开通后按后台要求发布/审批生效；仅能发文字不代表已有文件上传权限。应用的可用范围需包含本人。飞书后台管理员操作不能由本插件代替。
4. 选择「配置」，输入 App ID、App Secret、工作区和权限。密钥不回显，使用 Windows 当前用户 DPAPI 加密保存；不可把密钥发到群或提交 Git。默认只读；工作区可写或完全访问必须主动选择。本机 Codex 的 skills/MCP 配置仍由 Codex 管理，文件沙箱不等于所有外部业务工具的权限控制。
5. 选择「首次配对」，向自己的机器人私聊发送终端显示的临时 `/pair ...`。10 分钟内有效，不要转发给别人。配对后私聊仅本人可用；群聊按独立权限规则开放。收到配对成功后按 Ctrl+C 结束前台运行，再选择「后台启动」。
6. 选择「状态」，确认 `feishu` 和 `codex` 均为 `connected`，`paired` 为 true，`stale` 为 false。进程启动不代表连接就绪。
7. 正常私聊机器人。首次外部创建的项目任务可能要重开 Codex 后才在侧栏显示；消息历史在原生会话内连续保存。不要同时从桌面和桥接写同一任务。

需要登录 Windows 后自动运行时，确认后台启动正常，再选择「开机启动」。仅为当前 Windows 用户创建启动快捷方式；默认不启用。移动程序目录或升级后，需从新目录重新启用。可选择「关闭开机启动」移除。


## 日常使用

- `/help`：命令说明；`/status`：当前聊天状态。
- `/stop`：取消本聊天的排队任务并请求停止执行；等待终态确认，先前操作不一定撤销。
- `/new`：空闲时开始新聊天；原有历史保留。普通消息始终复用当前任务。
- `/answer 编号 回答`：回答指定的 Codex 问题。不可用聊天文字改变执行权限。
- `/retry`：重试本聊天首次发送起 45 分钟内的未知交付，保留原 UUID 和截止时间，不重跑模型任务。修复权限或网络后使用；超过时限的记录仍需本机核对，不能盲目重发。
- `/recover`：重新读取 Codex 终态并补交确认的结果，不重跑任务；无法确认时保持暂停。
- 输入支持文字、富文本、PNG/JPEG/GIF/WebP 图片（每张最大 10 MB）和文件（每个最大 25 MB），每条最多 5 个附件。不自动执行或解压附件。
- 富文本支持原生代码块（保留语言、缩进和换行）、Markdown 和分割线；表情转为文字标记，不再导致整条图文消息被拒绝。未知内容节点仍拒绝处理，避免静默丢失内容。原有上限不变：转换后文字最多 30,000 字符，入站 JSON 内容最多 100,000 字节。
- 文件输出仅从本聊天工作区 `.feishu-bridge/<chat>/outgoing` 通过专用工具交付，不能指定其他聊天。升级前创建的旧会话可能没有文件工具，用 `/new` 开启新会话后生效。
- 群聊默认关闭。由桌面管理员使用权限工具明确开放群、成员及是否需要 @。见下方群权限说明。


## 状态与故障

`queued` 表示排队，`running` 表示执行中，`completed` 表示模型完成，outbox 的 `sent` 才表示飞书确认回复已发送。当前运行实例遇到执行结果未知时，会暂停所有新模型任务，直到 /recover 确认原任务终态；文字回复和控制命令仍可处理。本机状态的 pausedForUnknownExecution 显示此暂停原因。

`unknown` 需要核对：执行可能已经发生，不能直接重发有副作用的请求。先尝试 /recover；仍无法确认时停止桥接，在 Codex 核对或停止对应任务，再从本机菜单选择「核对未知任务」并按提示确认。确认会记录人工处理、取消该聊天后续排队消息，不重跑原任务；不需要手改数据库。交付结果未知与执行未知是不同状态，交付未知不能直接无条件重发。`/status` 和本机状态会显示脱敏 HTTP 状态与飞书错误码，不记录原始响应头或错误正文；如 99991672 表示应用权限不足。

「诊断」只校验本机配置与飞书机器人身份，不等同完整消息权限或模型执行测试。密钥错误、权限不足、网络故障、Codex 登录失效分别需要修复后重启。未知审批请求会被拒绝；不会因用户随口说“同意”而提升权限。


## 本机管理工具

插件提供 bridge_status、bridge_doctor、bridge_start、bridge_stop、bridge_uninstall、bridge_permissions_get、bridge_permissions_set。启动请求成功不代表连接就绪；检查 feishu/codex=connected、paired=true、stale=false。MCP 连接状态与机器人连接状态不同。

## 群权限与个人资源

私聊默认仅主人，群聊默认关闭。每个群共享上下文，不同群和私聊独立。允许指定 senderIds，或配置 allowAllMembers=true（包括未来加入的人类成员）；非主人成员访问需明确接受 trustedLocalAccess。所有人共用当前 Windows 身份和所配置的本机能力，工作区目录不是完全访问模式的隔离边界。

权限变更使用 bridge_permissions_get/set 和 expectedRevision，等待空闲后停止后台、保存、重启，防止覆盖并发修改。飞书消息不能修改管理权限；管理命令仅主人，交互问答仅原请求人可回答。

个人资源访问需要单独安装官方 @larksuite/cli 并在配置时启用。授权卡片仅发给主人私聊；后台使用数据目录中的独立 CLI 配置，核对应用和用户，不覆盖其他应用登录。cli.state=ready 只说明应用凭据可用，个人 scopes 仍需授权。/stop 可取消授权等待。扫码创建机器人后仍需核对租户审批、事件与发布状态，不对已有配置重复 setup。

普通回复采用交互卡片与 lark_md；不保证文档链接显示原生正文预览。进度使用 Typing 表情，需要 im:message.reactions:write_only 或覆盖权限。没有正文或正文仅为 NO_REPLY 的正常完成任务不发空卡片，失败和中断仍有提示。

## 会话占用与独立后台

桥接启动时恢复已绑定会话并持续持有写入权。桌面可以看历史，但不能同时写同一会话。/stop 仅停止任务，不释放会话；需桌面接管执行时，停止后台并确认 stopped。共享规则编辑不需要接管，见下文。

后台通过当前 Windows 用户的计划任务运行，退出 Codex 桌面不影响已启动的服务。开机启动为单独的可选设置。系统策略不允许计划任务时，用独立终端前台运行；不要用桌面工具临时进程替代后台服务。

## 项目选择与桌面归组

工作目录、后台项目和桌面侧栏归属是不同状态。初始化先在 Codex 桌面添加工作目录；停止桥接后，运行 manage.ps1 -Action project（菜单 14）选择与桌面目标对应的已有项目，再启动桥接。选择保存到本配置，仅用于后续新会话，不移动已有历史。

不会自动创建后台项目。只有一个同目录项目时可自动选中；存在多个时必须明确选择，不按排序猜测。已选项目删除或根目录变化时不会自动换绑。没有可用项目时仍可对话，但新会话不指定项目。

status / bridge_status 的 projectBinding：backend_selected 表示后台目标已选定，selection_required 表示多个同目录候选，project_missing 表示未找到，selection_missing 表示已选项目不再匹配。desktopVisibility=unverified 不代表桌面已归组；旧运行版本缺少该字段时也不得当作验证通过。

桌面侧栏可能需要退出并重新打开后才显示新会话，不保证即时归组。仍未显示时，右键会话 → 移动到项目；保留历史，不修改 Codex 私有数据库或实验开关。

群规则 allowAllMembers=true 允许该已列出群的所有当前及未来人类成员发起任务，必须同时 trustedLocalAccess=true。无需读取群成员列表；私聊仍仅主人、未列出群不开放、主人管理命令限制不变。默认省略或 false 保留 senderIds 白名单。此权限允许成员使用当前本机执行权限。

静默回复：任务正常完成但没有正文，或最终正文仅为 NO_REPLY 时，不发送兜底卡片并撤销 Typing 表情；任务仍记录为已完成，重启恢复不会补发空回复。失败、中断及需要用户操作的提示仍保留。


## 共享规则热更新

统一设定维护在绑定工作区根目录 AGENTS.md。后台每轮执行前读取（UTF-8，最多 64 KiB），内容变化时用 thread/inject_items 注入已加载会话，不启动确认回合、不停止桥接。管理会话修改文件即可，不要逐个发送“同步规则”消息。正在执行的一轮不受影响，下一轮使用新版；建议临时文件加原子替换保存。空白、超限、已读取文件消失或注入失败时拒绝该轮，修复后重新发送请求。首次没有 AGENTS.md 的工作区保持原行为；不要通过删除文件撤销旧规则，应写清新的替代规则。

status 的 sharedRules 提供最近检查时间、内容哈希和本进程各 thread 的注入版本；它证明协议注入成功，不代表模型已逐条理解或完成确认。未收新消息的会话无需提前唤醒。仅热加载根目录此文件，不递归展开引用文件、不重载 Skill；私人指令仍仅限主人私聊。修改规则不扩大工具权限。

## 数据、升级与卸载

默认配置目录为 %USERPROFILE%\.feishu-codex-bridge，可通过 FEISHU_CODEX_HOME 或管理命令的 -DataDirectory 隔离。程序安装在 %USERPROFILE%\.feishu-codex-bridge-app，current.json 指向当前安装。数据含 DPAPI 加密凭据、收件、队列与交付记录；工作区 .feishu-bridge 保存附件，Codex 独立保存会话历史。没有自动保留期清理。

升级前等待空闲、停止后台、备份数据，安装到新目录后用相同数据目录启动。仅更新插件不会更新运行中的服务。保留旧运行目录与兼容的数据备份；不同数据版本不能盲目回退。移动或升级后重新配置可选自启动。

优先说“完整卸载飞书 Codex 桥接”或运行 manage.ps1 -Action uninstall。正常停止后清理对应计划任务、自启动及默认位置的当前运行文件，再移除插件。失败时停止后续删除，不强杀不相关进程。配置、附件、Codex 历史、旧备份与自定义安装目录保留。

Git/源码安装使用 manual 生命周期，必须先清理服务再移除插件。私有账号插件在成功绑定远端身份后支持轮询卸载检测：pluginLifecycle=watching 才表示生效。连续确认未安装并经过宽限期后清理；网络错误、账号变化、禁用和目录缺失不视为卸载。停止后台后不再检测。这不是官方卸载回调；状态不可用时使用手动完整卸载。

独立表情包消息会被静默忽略：飞书不提供其原图下载，因此不启动模型回合，也不发送不支持提示。普通图片和文字中的默认表情仍正常处理。
